# Smart-Palletization-of-Kuka-Robot-by-integrating-vision-system
Automated palletizing of 2.0 kg cardboard boxes using a KUKA KR 6 R900 robot. Co-designed a custom vacuum gripper (118.86 N holding force, four 40 mm cups at −0.6 bar, Techno ZK-15 ejector; within 1% of datasheet curves). Programmed in KUKA KRL with vision and proximity sensing, achieving 0.25 s vacuum build-up and zero slip.
